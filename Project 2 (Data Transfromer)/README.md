# 📌 Project Overview

**Data Transformer** is a comprehensive SQL project designed to strengthen practical knowledge of SQL operations using **MySQL**.

The project simulates a **Corporate Data Analysis System** consisting of three core business areas:

1. 👥 **Customer Information Management**
2. 📦 **Sales Transaction Processing**
3. 👨‍💼 **Employee Performance & Salary Data**

The project focuses on transforming and analyzing relational data using advanced SQL concepts such as:

- JOIN operations
- Subqueries
- Aggregate functions
- Date manipulation functions
- String manipulation functions
- Window functions
- `CASE` expressions
- Data filtering
- Data transformation
- Ranking and running totals

---

# 🎯 Objective

The main objective of this project is to develop practical SQL skills by working with related business tables and performing real-world data analysis tasks.

The project demonstrates how SQL can be used to:

- Retrieve related information from multiple tables
- Find matching and non-matching records
- Perform calculations using subqueries
- Analyze dates and time differences
- Transform and clean text data
- Calculate cumulative totals
- Rank business transactions
- Apply conditional discounts
- Categorize employee salaries
